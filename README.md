# JSON GUI Builder (starter)

Форма строится по JSON-спецификации: валидация спецификации и ввода, зависимости между полями
(`optionsSource`, `computed`, `visibleWhen`), коллекции (`array`, `matrix`, `list`), переводы RU/EN
и визуальный конструктор спецификации.

## Запуск

```
npm install
npm run dev
```

## Режимы
- **JSON** — спецификация текстом; загрузка из файла, копирование, скачивание.
- **Конструктор** — визуальная сборка формы: список элементов (drag-n-drop), редактор свойств,
  условия видимости, вычисляемые значения (с подсказками по полям), источники вариантов,
  граф зависимостей, импорт/экспорт JSON. Циклические зависимости создать нельзя: недопустимые
  поля просто не предлагаются в списках.
- **Предпросмотр** — только готовая форма (тот же `FormRenderer`).
- **Словарь** — общий словарь переводов (ключ → текст для RU/EN), экспорт/импорт.

## Тексты и переводы
Порядок поиска: `translations` самой формы → общий словарь → исходный `label`.
Русский — базовый язык (тексты в `label`), переводы нужны для остальных.

## Структура
- `src/core/` — логика без React (проверки, зависимости, выражения, переводы).
- `src/components/` — отрисовка формы. `src/builder/` — конструктор и словарь.

## Тесты
- `npm test` — логика (без браузера).
- `npm run test:e2e` — клики в настоящем браузере (нужны `playwright` с Chromium и `esbuild`:
  `npm i -D playwright esbuild`).
