# Руководство пользователя

## Запуск
```
npm install
npm run server     # сервер общего словаря и хранилища форм (порт 3001)
npm run dev        # интерфейс (в другом окне терминала)
```
Без сервера интерфейс работает: словарь хранится в браузере, а при появлении сервера синхронизируется.

## Как собрать форму
1. Вкладка **Конструктор** → выберите тип в списке «добавить элемент» → «Добавить».
2. Справа — свойства выбранного поля: подпись, обязательность, значение по умолчанию, варианты и т.д.
3. **Показывать по условию** — поле появляется, только когда выполнено условие по другому полю.
4. **Вычисляемое значение** — формула из других полей; подсказки-«фишки» вставляют имена полей и операции.
5. Результат сразу виден в форме справа. Введённое в форме значение **не сбрасывается**,
   пока вы правите конструктор (сбрасывается только у удалённых полей и полей со сменённым типом).

## Общий словарь переводов
Вкладка **Словарь**: ключ → текст для RU и EN, доступен всем формам (`labelKey: "мой_ключ"`).
- Строка статуса показывает связь с сервером: синхронизировано / сохранение / сервер недоступен.
- Правки отправляются через полсекунды после последнего изменения. Если сервера нет — они остаются
  в браузере и уйдут, когда связь вернётся (или по кнопке **Обновить с сервера**).
- Чужие правки подтягиваются кнопкой «Обновить с сервера» и автоматически при возврате в окно.
- **✎** рядом с ключом — переименование (Enter — применить, Esc — отмена). Если ключ используется
  в открытой форме, появится напоминание обновить там `labelKey`.
- При первом подключении ключи, накопленные в браузере, которых нет на сервере, поднимаются на сервер.

## Формы на сервере
Кнопки под панелью JSON: **Сохранить на сервер** (потом — «Обновить на сервере» / «Сохранить как новую») и
список **Открыть с сервера…**. Сервер не принимает некорректные спецификации и сообщает число ошибок.

## Что не умеет (пока)
- Интерфейс конструктора только на русском (формы и словарь — RU/EN).
- Нет авторизации; два человека, правящие один ключ одновременно, — побеждает последний.
- Начальный расчёт зависимостей замедляется на цепочках из сотен полей (на реальных формах не заметно).
